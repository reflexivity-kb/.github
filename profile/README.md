## Ask the Knowledge Base with AI

Prefer asking a question to browsing folders? You can use the Reflexivity knowledge base as GitHub repository context in GitHub Copilot, ChatGPT, or Claude.

- **GitHub Copilot** — Open [reflexivity-kb/docs](https://github.com/reflexivity-kb/docs) on GitHub, open Copilot Chat, and ask about the repository. Copilot can use the current repository as context. [GitHub instructions](https://docs.github.com/en/copilot/tutorials/explore-a-codebase)
- **ChatGPT** — Connect GitHub from **Apps / Plugins** (availability depends on your plan and workspace), authorize accessible repositories, and ask ChatGPT to use **reflexivity-kb/docs** as its source. [OpenAI instructions](https://help.openai.com/en/articles/11145903)
- **Claude** — In a chat, choose **+ → Add from GitHub**, or add GitHub to Project knowledge, then select **reflexivity-kb/docs** or paste its repository URL. [Claude instructions](https://support.claude.com/en/articles/10167454-use-the-github-integration)

A useful starting prompt:

> Use `reflexivity-kb/docs` as the source of truth. Answer my question from the most relevant Reflexivity documentation and cite the files or pages you used.

You can ask in English, Japanese, Korean, Simplified Chinese, or Traditional Chinese.

If you have approved access to [Reflexivity Client Resources](https://github.com/reflexivity-kb/client-resources), you can also add or authorize that repository in your AI assistant. Your existing GitHub permissions still apply.
