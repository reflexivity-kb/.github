### 1. 🤖 Ask with AI / AIに質問 / AI에 질문 / 用 AI 提问 / 使用 AI 提問

The knowledge base is large. Instead of reading every page, connect the GitHub repositories to GitHub Copilot, ChatGPT, or Claude and ask questions directly. Each language page above includes connection instructions and verified example questions.

Use [**reflexivity-kb/docs**](https://github.com/reflexivity-kb/docs) for public material. If you have approved access, you can also add [**Reflexivity Client Resources**](https://github.com/reflexivity-kb/client-resources) for Technical Reference, REST API, and AI/MCP documentation.

You may ask in **any language supported by your AI assistant**. Your question is not limited to the six source languages in which the KB is published.

### 2. 📚 Browse pages / ページを見る / 페이지 보기 / 浏览页面 / 瀏覽頁面

Prefer to browse? Choose your language above. The public KB is organized into **Use Cases, Guides, Product, Articles, and Releases**. Use Cases can also be browsed by persona, insight type, and asset class.

### 3. 💬 Ask support / サポートに質問 / 지원 문의 / 联系支持 / 聯絡支援

If the material you need is missing, email **jim@reflexivity.com**.

Approved Client Resources users can also use [**GitHub Discussions**](https://github.com/reflexivity-kb/client-resources/discussions). When asking, include the relevant **hard link or page title** whenever possible.

To keep GitHub notifications quiet, open the repository's **Watch** menu and choose **Participating and @mentions**. Choose **Ignore** if you do not want repository notifications.
